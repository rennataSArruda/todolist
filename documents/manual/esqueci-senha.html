Recuperação de acesso

Esqueci minha senha

Solicite a recuperação e defina uma nova senha usando um token válido, sem que o sistema revele se uma conta existe.

Fluxo

1
Informar identificador

Digite o usuário ou e-mail no formulário de recuperação.

2
Solicitar instruções

O sistema recebe a solicitação e mantém uma resposta genérica.

3
Usar o token recebido

Com o token de recuperação, informe e confirme a nova senha.

4
Entrar novamente

Volte ao login e crie uma nova sessão com a senha atualizada.

Solicitação

POST/public/auth/forgot-password

A resposta esperada é 204 No Content.

Payload 
{
  "identifier": "usuario-ou-email"
}
Mensagem recomendadaSe os dados estiverem corretos, enviaremos as instruções para redefinir sua senha.

Redefinição

POST/public/auth/reset-password
Payload 
{
  "token": "token-recebido",
  "newPassword": "nova-senha"
}
