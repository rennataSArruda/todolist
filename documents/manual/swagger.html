Referência técnica

Swagger e API

Use o Swagger para consultar contratos e testar endpoints no ambiente de desenvolvimento local.

Como acessar

URL local 
http://localhost:8080/swagger-ui.html
Ambiente de desenvolvimentoO Swagger fica disponível somente no profile dev; não o exponha em produção.

Fluxo de teste

1
Inicie a API

Suba a aplicação com o profile de desenvolvimento.

2
Abra o Swagger UI

Acesse a URL local no navegador.

3
Use Authorize

Informe as credenciais; o Swagger usa o endpoint próprio de token.

4
Execute o endpoint

Escolha Try it out, preencha os dados e selecione Execute.

Autorização

POST/public/auth/token

Este endpoint suporta o botão Authorize do Swagger. O frontend deve usar /public/auth/login.

CuidadosChamadas de criação, edição e bloqueio alteram dados. Use informações de desenvolvimento e nunca compartilhe tokens ou senhas.
