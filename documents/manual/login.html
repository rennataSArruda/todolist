Acesso ao sistema

Login

Fluxo de entrada para usuários já cadastrados. Após a autenticação, a aplicação usa os tokens retornados para acessar as rotas privadas.

Objetivo

Validar usuário e senha, iniciar a sessão e carregar as permissões atribuídas ao perfil da conta.

Fluxo

1
Informar credenciais

Preencha o usuário e a senha cadastrados.

2
Enviar autenticação

Selecione Entrar para validar os dados.

3
Criar sessão

O sistema recebe access token e refresh token.

4
Acessar recursos

As funcionalidades são exibidas conforme as permissões do usuário.

Contrato HTTP

POST/public/auth/login

Endpoint oficial de login para a aplicação e integrações.

Payload 
{
  "username": "seu-usuario",
  "password": "sua-senha"
}
