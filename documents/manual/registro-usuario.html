Gestão administrativa

Cadastro de usuários

A criação de contas é administrativa: não existe auto cadastro público. A ação depende de uma sessão autenticada com a permissão correspondente.

Dados necessários

Campo Uso
username Identificador usado no login.
email Identificação e recuperação de acesso.
name Nome de exibição do usuário.
password Senha inicial; não é devolvida nas consultas.

Fluxo

1
Acessar a gestão de usuários

Entre com uma conta que possua permissão para criar usuários.

2
Preencher os dados

Informe usuário, e-mail, nome e senha inicial.

3
Salvar o cadastro

Confirme a operação e comunique as credenciais com segurança.

AtençãoNão compartilhe senhas em canais públicos. Se a opção não estiver disponível para você, solicite o cadastro a um administrador.

Contrato HTTP

POST/api/usuario

Exige Authorization: Bearer <accessToken> e permissão para criar usuários.

Payload 
{
  "username": "novo.usuario",
  "email": "usuario@exemplo.com",
  "name": "Novo Usuário",
  "password": "senha-inicial"
}
